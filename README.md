# System Engineering & DevOps

Shell scripting, Linux system administration, networking, and web infrastructure exercises completed during the ALX Software Engineering Programme.

## Topics

- Shell basics, file permissions, redirections, and variable expansion
- Processes, signals, and Bash scripting
- Networking fundamentals and regular expressions
- Web infrastructure, HTTP, APIs, and debugging
- Server configuration, monitoring, and deployment concepts

## Repository Structure

Exercises are organized by topic in separate directories. Each directory contains the scripts and supporting files for its respective tasks.

## Tools & Technologies

Bash · Linux · Shell · Networking · HTTP · Git
