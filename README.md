# ALX System Engineering & DevOps

Shell scripting, Linux fundamentals, networking, and introductory web infrastructure exercises completed as part of the **ALX Software Engineering Programme**.

This repository documents hands-on practice with the command line and operating-system concepts, progressing from everyday shell operations to process management, APIs, monitoring, and web-stack debugging.

## Topics covered

| Area | Topics |
| --- | --- |
| Linux and shell | Navigation, files, permissions, input/output redirection, environment variables, expansions |
| Bash scripting | Loops, conditions, text parsing, regular expressions |
| Operating systems | Processes and signals |
| Networking | Introductory networking concepts and command-line networking tools |
| APIs | Advanced API exercises |
| Operations | Web-stack debugging and monitoring |

## Working with the exercises

Most folders contain standalone exercises rather than one application. Browse a topic folder, read any task-specific instructions, and inspect the scripts or configuration files. Shell scripts may depend on a Linux environment and should be reviewed before execution.
